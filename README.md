#NOTA parcial-programacion1
Sistema de gestion de notas de alumnos



#Funcionalidad
- Carga de alumnos con validacion de nombre y notas
- Listado de alumnos con sus dos parciales
- Estadisticas: promedio general, mejor y peor promedio (con nombre) y cantidad de promocionados, aprobados y desaprobados
- Busqueda de un alumno por nombre



#Como ejecutarlo
Requiere Python 3.
main.py


#estructura
-`main.py`: menu principal y entrada del programa
- `validaciones.py`: validacion de datos ingresados
- `procesamiento.py`: calculos y estadisticas
